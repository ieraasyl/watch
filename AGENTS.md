# Repository guidelines

- Do not use em dashes or en dashes unless explicitly requested.
- Stay on the current branch unless the user asks for another branch.
- Use Conventional Commits with a short imperative subject and no body or trailers.
- Keep commits focused, stage only relevant changes, and review the staged diff.
- Run `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, and `cargo test` before handing off Rust changes.
